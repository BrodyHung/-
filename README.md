# Medical Packaging Geometry Optimizer — 醫療包裝幾何效率計算機

React + TypeScript + Vite，SVG 互動視圖，純前端，不需資料庫。預設尺寸都是「示範值」，不是官方產品尺寸或 CAD 校準成果。

## v1.1 包裝輪廓修正

預設使用 **本體＋左右堆積餘料**，不再用完整平放袋材矩形作為組裝後的物品輪廓。

- 「單側堆積餘料延伸 e」指本體側邊到**組裝後**袋材最外端的水平距離，左右對稱；預設手動輸入。
- 左右袋材用「本體及兩個側端點的凸包」作近似，從本體向側端收窄。圓形本體的過渡線與圓相切，不是任意將圓塞入長矩形。
- 手動模式下，即使平放袋長或袋寬很大，也不會蓋過 e 或放大上下距離。實體上下高度由本體決定：圓形為 D，長方形／圓角長方形為本體俯視寬度。
- e 必須以組裝後形狀量測或設計規格支持。**單一延伸量不足以證明真實袋材會形成此凸包**，本工具不計算袋材可壓縮性、褶皺密度或封口形狀；若實際餘料較厚，應改用實測外廓。畫面與文件均標為近似模型。
- 可選「由平放袋長產生候選」：e = max(0, (L_bag − D)/2)，僅產生候選，不宣稱袋材確實可如此折疊／堆積。
- 保留「完整平放矩形（舊模型）」供比較。匯入沒有新模型欄位的舊 JSON 或舊儲存方案時，會保留平放矩形與手動 CAD 尺寸，避免悄悄改變歷史結論；要採新計算，請切換包裝模型並開啟自動貼合。

## 上下貼合與側邊反算

「自動貼合包裝（蜂巢與井字同步）」預設開啟。此處貼合保留指定緩衝及安全間隙，沒有壓縮本體、袋材或緩衝層。

令 g = 紙緩衝層厚度 + 額外安全間隙，t 為該結構板厚。圓形本體在新模型下：

```text
包絡寬度 = D + 2e
包絡高度 = D
六角上下內部淨距 = D + 2g
井字內部淨長 = D + 2e + 2g
井字內部淨寬 = D + 2g
```

一般形狀使用解析支撐函數 S(nx,ny)，表示物品在該單位法向方向的最遠距離。新包絡的支撐為：

```text
S(nx,ny) = max(本體支撐, (D/2 + e) × |nx|)
圓角矩形本體支撐 = (D/2−r)|nx| + (本體寬/2−r)|ny| + r
圓形本體支撐 = D/2
```

角度為 θ、上下中心線半距 v、中心線壁距預留 m = g + t/2 時：

```text
v = S(0,1) + m
s = v / sin θ
a = 2 × [S(sin θ, cos θ) + m − v cos θ] / sin θ
```

a 僅以 0.0001 mm 下限防止浮點退化。計算後仍逐邊驗證解析支撐與淨空，不只比較寬高。因此角度改變時上下貼合高度保持不變，a 與 s 同時重新計算，側邊隨 e 改變。角度搜尋同樣使用這套反算。

自動模式下 a、s、目標寬高及井字淨尺寸欄位顯示實際反算值，不能手動修改。關閉自動貼合後可輸入原始 CAD 尺寸、以寬度或高度控制斜邊，或利用周長產生候選。周長不能取代容納檢查。

## 中心線幾何與淨空

```text
u = s cos θ；v = s sin θ（JavaScript 先將角度轉為弧度）
W = a + 2u；H = 2v
A = H(a + u)；P = 2a + 4s
頂點 = (−a/2,−v), (a/2,−v), (a/2+u,0),
       (a/2,v), (−a/2,v), (−a/2−u,0)
```

各中心線支撐邊向內偏移 t/2，得到紙板內部淨區；再向內偏移 g，得到容納安全區。過度內縮導致半平面不相容時視為空淨區。本體曲線與袋材包絡均以解析支撐檢查，SVG 的曲線取樣僅用來繪圖。

外箱邊界檢查使用中心線向外偏移 t/2 的完整多邊形，包含六角尖端的斜接伸長。包裝與整體排列可分別旋轉 90°；兩種結構使用相同物品輪廓、緩衝、安全間隙及外箱。板厚或隔板高度不同時，畫面會提示比較條件不同，可按鈕同步。

## 規則排列搜尋

逐格建立多邊形，使用 SAT 分離軸定理檢查碰撞：邊界接觸允許、內部正面積重疊拒絕。空間索引僅用來縮減檢查對象，最終仍以 SAT 判定。

- 井字：中心線格距 = 淨長／寬 + t，水平／垂直內隔板數決定搜尋行列上限，計入外圈封閉隔板材料。
- 共邊蜂巢：列中心距 a+u、同列縱距 2v、奇偶列錯位 v。另搜尋外包矩形直列及自訂錯位規則，並搜尋整體旋轉。
- 非共用壁模式用外擴紙板輪廓檢查碰撞，獨立壁不去重。共用壁模式容許中心線多邊形邊界相接。
- 最外側單元完整紙板輪廓不可超出箱壁間隙。定位片左右交替排列，保守預留左右完整側帶，長寬與數量同時計入占地及材料；此配置不表示已驗證卡榫或連接方式。
- 每軸最多 40 格、角度最多 251 組。每個角度在這些規則中保留最大裝載配置，同件數以較少總板材選擇規則；再依使用者目標排列各角度。未窮舉任意相位、自由旋轉、混合方向、任意單元刪減與非規則拼排。

所有結果明確標為**規則排列搜尋結果，不是全域最佳解**。角度目標值在 1e−6 容差內相同時列出並列首選；無解時保留失敗原因。修改輸入後，現有搜尋表會提示它是舊快照，需重新搜尋。

## 材料與效率

實際需要的中心線邊段依方向與法向位置分組，再以投影區間聯集消除完整或部分共用壁。幾何容差約 1e−6，直線分組取 5 位小數。

| 類別 | 計算 |
| --- | --- |
| 理論隔板材料 mm² | 有效中心線總長 × 隔板高 × 層數 |
| 裁切展開估算 mm² | 理論材料 + 每格加工預留 + 每層折返 + 定位片面積 |
| 含損耗總板材 mm² | 裁切展開估算 × (1 + 製造損耗率/100) |

JSON 的 pieces 記錄每個連續直線段的「段長 × 隔板高 × 層數」。蜂巢尚未決定連續折板如何分片、折彎補償、刀縫、實際扣槽、紙板紋向與大板排版，不能當成完成驗證的刀模。損耗加成也不等同實際刀模排版的精確餘料。

- 裝載密度 = 件數 / 外箱內部體積（畫面另換算 件/L）。
- 裝載提升率 = (蜂巢件數 / 井字件數 − 1) × 100%。
- 總紙板減量率 = (1 − 蜂巢總板材 / 井字總板材) × 100%。
- 每件板材 = 總板材 / 件數；每件減量率同樣比較兩組每件值。
- 正值為提升／減量，負值為降低／增加；分母為零或無裝載時以「—」顯示不可定義的值。
- 空間利用率保留「單層本體總面積 / 箱底面積」及「本體面積 / 單格內部淨面積」。**本體面積與袋材包絡面積不同**，圖形變大不會被冒充成醫材實體面積。
- 三種角度目標：最大件數、最少每件總板材、最小排列包絡體積。固定外箱的容積相同，因此第三目標採排列實際包絡體積；未固定需求件數，可能偏好少量裝載，應同時查件數。

層高 = max(隔板高, T + 2g)；多層數 = floor((箱高 − 2箱壁間隙) / 層高)。不含層間承重板、上下蓋、外箱紙板及封箱材料。1 cm² = 100 mm²；1 L = 1,000,000 mm³。工具不含有限元素分析、承重、跌落、緩衝或滅菌屏障驗證。

## 執行、資料與匯出

Node.js 24、pnpm 11.25.0，在專案根目錄執行：

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
pnpm preview
```

安裝僅允許 esbuild 的必要建置腳本。也可用 npm install / npm run dev / npm test / npm run build；CI 以 pnpm-lock.yaml 鎖定版本。正式輸出 dist，需 HTTP 伺服器提供，不能直接雙擊來源 index.html。

三個主要視圖：單格幾何、同尺度整箱俯視、角度圖表及比較表。輸入即時更新當前計算；搜尋以按鈕啟動並保留參數快照。儲存方案使用 localStorage，最多 30 組，可命名、載入、刪除及比較兩組。

CSV 匯出當前兩組及最近搜尋；PNG 匯出目前選取的 SVG；JSON v2 包含設定、有效幾何、結果及搜尋快照，匯入只採設定並重新計算。JSON 可跨裝置備份，localStorage 依瀏覽器與來源區隔。

33 項自動測試包含原有幾何、碰撞、外箱邊界、共用材料、旋轉、輸入與匯出設定驗證，以及新模型的單側實測餘料、上下貼合、側邊反算、平放袋尺寸不干擾手動模型、零餘料、圓角解析支撐及舊設定相容。

## GitHub Pages

部署目標為 BrodyHung/- 的 main 分支，公開網址 https://brodyhung.github.io/-/ 。以 Actions 最新結果判斷版本部署是否成功。

獨立部署儲存庫的 workflow 位於 .github/workflows/pages.yml，安裝依賴、執行測試、建置 dist 並發布。原工作區子目錄版本對應上一層 .github/workflows/medical-packaging-pages.yml。若移動目錄需同步 working-directory 與 artifact path。

GitHub Settings → Pages 的來源設為 GitHub Actions。推送 main 或手動觸發會部署，PR 僅測試。Vite 使用 base: './' 支援儲存庫子路徑，無路由重導或 API key 需求。
